# 默认“我的”、已有文件夹与录音返回

用户目标：保留现有手机首页与已可用的录音功能，打开应用默认进入“我的”，能浏览账号已有文件夹及其中记录，结束录音不再落到电脑详情页。

首页适配由独立 `mobile-library.js` 负责。先选中官网手机页已有的“我的/记录”，在原记录滚动容器内增加文件夹导航。目录由官网公开到页面的 `window.tingwuRequest` 客户端调用 `getDirList` 读取，复用该客户端的登录会话；文件夹内记录通过 `getTransList` 的 `filter.dirId` 读取。根视图保留官网原有记录卡片，选中文件夹后展示子文件夹、面包屑和分页记录列表，点击记录进入官网手机详情路由。所有读取均只读，文件名用 textContent，过期请求不得覆盖新选中的文件夹。

录音返回由 Android Activity 的会话状态和精确官网路由共同判断。完成后进入 `/home`、`/doc/transcripts/{id}` 或 `/discover/transcripts/{id}` 时，只有录音会话已进入且没有活动采音，才返回手机首页。覆盖 SPA 路由更新与完整页面导航，确认结束前不关闭页面。结束确认弹窗按手机宽度排列。

验证步骤：先复现默认发现、缺少文件夹和完整导航不能返回；覆盖目录层级、指定目录记录、手机详情跳转、错误重试、返回全部记录和收藏切换；验证弹窗窄屏布局及录音保存后的 SPA/完整导航；运行 JS、Android 单元测试和 lint，生成同签名的 1.0.12 APK。
