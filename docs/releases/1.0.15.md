# 通义听悟 Android 1.0.15

移除与小米顶部系统播放面板重复的大悬浮条，恢复只通过系统媒体入口进行跨应用控制的交互。

- 沿用已经可以展开播放控制面板的顶部“听”入口，继续通过同一个 Android MediaSession 暂停、继续和控制进度。
- 删除独立跨应用悬浮窗及其授权提示，不再声明或申请“显示在其他应用上方”。旧版保留的悬浮设置不会再次创建控件，无需用户清除应用数据。
- 应用内播放条、通知栏、锁屏与息屏播放继续可用。系统媒体通知的样式、元数据和控制回调保持原有实现。
