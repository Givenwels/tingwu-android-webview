# 通义听悟 Android 1.0.14

修复切换文件夹中的录音时始终打开第一条、息屏后播放暂停，以及详情页返回按钮被系统状态栏遮挡的问题，新增可选的跨应用悬浮播放控制。

- 文件夹记录通过官网卡片入口导航，每次正确更新详情正文、共享状态和实际音频来源；返回后保留文件夹及滚动位置。打开首页仍默认进入手机“我的/记录”。
- 播放使用同一个官网播放器，增加 Android MediaSession 和媒体通知，可在通知栏、锁屏暂停、继续及控制进度。兼容官网自动隐藏暂停策略，同时保留真实页面可见状态与用户主动暂停操作。
- 适配系统状态栏、导航栏和屏幕开孔安全区域；应用底部播放条独立占位，避免遮挡网页操作。
- 可选悬浮播放条在切到其他应用后显示，支持拖动、暂停、继续、返回和停止。首次播放时说明用途，由用户决定是否授予“显示在其他应用上方”；长按应用底部播放条可更改设置。不授权仍可正常播放，并使用应用内及媒体通知控制。
- 仅在实际播放时进入媒体播放前台状态，额外 CPU 唤醒锁只在实际播放且息屏时持有。暂停后释放锁并退出前台，保留可继续的媒体会话；停止或清除应用任务后清理通知和悬浮条。不使用静音保活、常亮屏幕、循环心跳、无障碍或开机自启。
- 播放已有音频不需要麦克风权限，麦克风仍只在用户进入实时记录时申请。没有普通通知权限时，带真实 MediaSession 的媒体通知仍可正常出现；悬浮窗授权只影响跨应用控制条。
