# 通义听悟 Android 1.0.18

修复文件上传后任务状态可能一直停留在“转写中”的客户端问题，并让进度展示符合实际含义。此版本不承诺加快云端识别。

- 复现官网 uni-tingwu 2.9.82 的任务清理问题：成功路径先调用 unWatch，再调用包含第二次 unWatch 的 destroy。原实现第二次找不到任务时执行 splice(-1,1)，误删除另一个任务的监听，甚至关闭整个状态查询定时器。现在退出监听具有幂等性，重新加入任务和强制清理仍按原逻辑运行。
- 手机 H5 上传已有 XMLHttpRequest 的真实进度回调，原实现同时每秒增加1%的模拟进度。现在停止这个模拟定时器，保留真实上传回调，不修改上传内容、接口或取消操作。
- 云端“转写中”的百分比原本由预计完成时间推算，并非已识别音频时长或服务器实际百分比。现在隐藏该推算进度条，保留预计时间，并明确说明其含义。
- 适配仅作用于通义听悟顶层手机页，不增加云端接口请求、后台服务、轮询或权限。继续使用官网原有转写、保存与结果通知流程。

截图中的17:49是预计等待时间，不能据此推断每秒只识别一秒音频。25MB也不能单独确定音频时长。实际云端耗时仍受录音时长、服务端排队和处理情况影响；本次没有用户账号和任务日志，不能断言截图里的单条任务就是上述客户端问题导致。

录音类小米超级岛仍未完成厂商审核和 App ID 配置，默认包使用普通录音通知。这个限制不是麦克风或悬浮窗权限不足，不能将此版本描述为已经启用原生录音岛。
