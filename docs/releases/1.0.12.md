# 通义听悟 Android 1.0.12

首页保持手机版，打开后默认进入“我的 → 记录”。新增“我的文件夹”，显示通义听悟账号中已有的目录、子文件夹和分类记录，支持搜索及分页；点击记录进入官网手机详情页。“全部记录”继续使用官网原有卡片，收藏、分享等标签仍可使用。

本版也包含此前尚未同步到 GitHub 的安卓修复：

- 移除顶部额外的“PC兼容”和“实时记录”悬浮按钮，使用官网自带的实时记录入口。
- 独立录音页面使用桌面浏览器能力，按手机宽度纵向显示录音设置、转写、控制条和笔记。
- 系统麦克风授权完成后再初始化官网录音，补齐 WebView 采音所需音频设置权限。
- 修正录音开始后的裁切、工具栏重叠和笔记偏移，以及结束确认弹窗的手机布局。
- 录音结束后检测页面内和整页跳转，返回手机版“我的”；采音活动时保留录音页。
- 播放服务只随实际音频播放启停，正式包关闭调试并使用固定专用证书。

下载 `tingwu-v1.0.12-release.apk`，大小 682,897 字节（约 0.7 MB），支持 Android 8.0 及以上。与此前发放的 1.0.7—1.0.11 正式包签名相同，可直接覆盖安装。旧 debug 包的包名不同，属于另一份安装。
