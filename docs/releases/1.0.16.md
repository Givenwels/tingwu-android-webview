# 通义听悟 Android 1.0.16

修复其他应用的视频打断听悟后，播放按钮状态错误，以及恢复失败后顶部播放控制入口丢失的问题。

- 官网 AudioPlayer 的暂停回调只发事件，外部播放器直接暂停底层音频时，界面仍可能保留“播放中”。现在根据真实音频事件同步按钮状态，返回应用后可以一次点击继续。
- 后台播放服务恢复被拒绝或超时后保留录音标题、进度、暂停媒体会话和重试入口，释放前台状态及唤醒锁，不再直接清空整个会话。
- 暂停期间服务被关闭后，返回应用可重建暂停控制。恢复控制时不会自动开始播放，等待用户继续操作。
- 被动后台恢复失败不会在其他应用中弹出打断提示；用户主动恢复仍保留必要的失败提示。系统音频焦点规则继续生效，观看其他应用视频时不会强行抢回声音。
- 保留系统顶部“听”的媒体入口，不增加跨应用大悬浮条或悬浮权限，也不使用静音保活、轮询心跳或常亮屏幕。
