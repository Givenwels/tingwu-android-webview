# 通义听悟 Android 1.0.13

修复文件夹后续记录无法显示，以及息屏后录音中断的问题。

- 文件夹使用独立滚动区域，向下滚动接近底部时按需读取下一页，也可点击“加载更多”。兼容服务端返回较短分页、total/totalNum 或无总数的情况，避免空页、重复页和并发加载。
- 实际录音时启用带状态通知的麦克风前台服务，支持息屏后持续采音。通知可返回同一个录音页面。
- 不再强制录音页亮屏。额外 CPU 唤醒锁只在实际录音且息屏时持有，并带超时保护；亮屏、暂停、结束、页面离开、渲染进程退出和退出录音后释放对应资源。
